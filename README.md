# Zihan Chen’s personal website

Personal website with research, CV, teaching materials, and life outside work.

## Updating the site

- Edit the HTML files directly. `index.html` is the homepage.
- Shared styles and navigation behavior are in `assets/site.css` and `assets/site.js`.
- Replace `assets/ZihanChen-CV.pdf` to update the CV. Update its `?v=` value in `cv.html` and `vitae.html` so browsers load the latest version.
- Keep the `.nojekyll` file so GitHub Pages serves these static files directly.

GitHub Pages publishing source: `main` branch, repository root.
